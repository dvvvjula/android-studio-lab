# PAM_03.1

This branch contains the first exercise of the 3rd laboratory of **Mobile Applications Programming**, where we learned about **Intents** in Android.  

The main activity contains several buttons demonstrating different types of intents and interactions between activities and other apps:

## Features

- **New Activity**  
  Opens a new activity within the app.

- **Intent with Parameter**  
  Passes a parameter from the main activity to a second activity and displays it on the new screen.

- **My Favorite Website**  
  Opens a predefined URL in the web browser when clicked.

- **Directions to the University**  
  Opens Google Maps at specified coordinates and marks the location.

- **Open Calendar**  
  Opens the default calendar app associated with the Google account.

- **Launch Camera**  
  Opens the device camera to take a photo.


## Learning Goals

- Understand and implement **explicit intents** (opening a new activity).  
- Pass data between activities using **intent extras**.  
- Use **implicit intents** to interact with external applications like the browser, maps, calendar, and camera.  
- Learn to handle **URIs** for different types of external content.
