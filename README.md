# 02.1_PAM

This branch contains the second laboratory exercises for the Mobile Applications Programming course. The goal of the first exercise was to get familiar with Android layouts, user input handling, and basic UI interactions in Android Studio.

The work involved creating an application that:

- Accepts a numeric input from the user representing an amount in a base currency.  
- Provides three buttons to convert the entered amount into different currencies: **USD**, **EUR**, and **CHF**.  
- When a button is clicked, the application converts the amount using a predefined exchange rate and displays the result in **PLN**.  
- Handles exceptional cases:  
  - If no amount is entered, the application displays a warning message.  
  - If the input is invalid (not a number), an error message is shown.

This lab exercise focused on working with LinearLayout and ConstraintLayout to arrange UI elements, connecting XML components to Java code using findViewById, implementing button click events to perform currency conversion, and basic exception handling for user input to ensure the application behaves correctly in edge cases.
